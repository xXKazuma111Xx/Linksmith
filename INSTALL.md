# Linksmith — Installation Guide

## How to Install in Google Chrome

### Step 1 — Download the extension
Download the `CampaignNameGenerator.zip` file and **unzip** it to a folder on your computer.

---

### Step 2 — Open Chrome Extensions
In your Chrome browser, go to:
```
chrome://extensions
```
Or navigate via: **Menu (⋮) → Extensions → Manage Extensions**

---

### Step 3 — Enable Developer Mode
In the top-right corner of the Extensions page, toggle **Developer mode** ON.

---

### Step 4 — Load the extension
Click **"Load unpacked"** (top-left), then select the unzipped `campaign-namer-extension` folder.

---

### Step 5 — Pin it to your toolbar
Click the **puzzle piece icon** (🧩) in the Chrome toolbar, find **Linksmith**, and click the **pin icon** so it stays visible.

---

## You're all set! 🎉
Click the icon in your toolbar to open the extension.

---

## How to Update (when a new version is released)

1. Download and unzip the new version
2. Go to `chrome://extensions`
3. Click the **refresh icon** on the extension card — or click **"Load unpacked"** and select the new folder

---

## Troubleshooting

**The extension doesn't appear after loading?**
Make sure you selected the folder that contains `manifest.json`, not a parent folder or the zip file itself.

**The Base URL doesn't auto-fill?**
Auto-fill only works on regular `http`/`https` pages. It won't trigger on Chrome internal pages like the Extensions page or New Tab.
